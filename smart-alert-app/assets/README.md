# Thư mục Assets (`smart-alert-app/assets/`)

Thư mục này dùng để lưu trữ các tài nguyên tĩnh của ứng dụng (icon, splash image, âm thanh cảnh báo tuỳ chỉnh nếu mở rộng ở LAB 2/LAB 3).
Hiện tại cấu hình mặc định trong `app.config.ts` sử dụng màu nền Splash `#0F4C81` và bộ icon vector `@expo/vector-icons` (`MaterialCommunityIcons`) để ứng dụng có thể prebuild và đóng gói APK ngay lập tức mà không phụ thuộc file ảnh bên ngoài.
